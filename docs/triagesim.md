# TriageSim docs (`/triagesim/`)

TriageSim's docs are the first "docsite" on this site — see
[docs/adding-a-docsite.md](adding-a-docsite.md) for how the whole mechanism
works (front matter, nav data, shared theme, the port script) and how to add
another one. This file just covers what's specific to TriageSim.

- **Only linked from its publication**, not the main nav: the "Docs" button
  on `content/publications/preprints/07-dipankar-triagesim-preprint.md`
  (`links.docs: /triagesim/`). The TRIBOT/NHMRC grant (see
  [docs/grants.md](grants.md)) just lists that publication — it carries no
  link of its own to the docs.
- **Source repo**: sibling `triagesim-website` (a standalone MkDocs Material
  + mkdocstrings site) — prose is Markdown under its `docs/`, the API
  reference is generated from the `triagesim` Python package's docstrings.
  Never hand-edit `content/triagesim/` here; it's fully regenerated by the
  port script.
- **Config**: `scripts/port-docsite.py`'s `CONFIG` block (`DOCSITE_KEY =
  "triagesim"`, `SITE`/`OUT`/`BASE`, and the `PAGES` list) and
  `data/docsites/triagesim.yaml` (sidebar nav). Both need updating together
  if a page is added/renamed/removed in `triagesim-website/mkdocs.yml`'s
  `nav:`.

## Updating the docs

1. Make your changes in `triagesim-website` — Markdown under `docs/`, or
   docstrings in the `triagesim` package itself.
2. Rebuild that site and re-run the port script from here:

   ```bash
   cd ../triagesim-website
   .venv/bin/mkdocs build

   cd ../unswnlp.github.io      # this repo
   python3 scripts/port-docsite.py
   ```

3. Preview with `hugo server` and check the changed page(s) under
   `/triagesim/...`, then commit `content/triagesim/` (and any layout/CSS
   changes) here like normal.

## A note on the source repo's own MkDocs config

`triagesim-website/mkdocs.yml` and `docs/stylesheets/extra.css` in that repo
are themed to roughly match this site (in case anyone runs `mkdocs serve`
there directly to preview), but **those files no longer affect what's
actually deployed** at unswnlp.github.io/triagesim/ — only the rendered
`<article>` content the port script extracts does. The real styling lives in
`assets/css/docsite.css` here.
